# B0 — The `count` trap

What does `terraform plan` show when a middle landlord account is removed from the list? Why is
that dangerous here? What's the fix?

Answer:

This is dangerous because terraform creates the buckets using 'count' so each bucket is identified by its position in the landlord account list and it might change the list and ownership of accounts
output eg: aws_s3_bucket.landlord_media[0]
           aws_s3_bucket.landlord_media[1]

The fix here is to use for_each with the landlord_account_id key instead of list position, this will give us an output of : 
eg: aws_s3_bucket.landlord_media["la-001"]
